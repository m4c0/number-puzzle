# Casually Casual Sliding Puzzle

A casual number sliding puzzle game.

Slide the tiles to solve each board. Features 30 different backgrounds, no ads,
and it’s free to play.

Currently available on:
* [Apple Store][app-store] (signature files are not part of the source code).
* [itch.io][itch]

[app-store]: https://apps.apple.com/pk/app/casually-casual-sliding-puzzle/id6781833428
[itch]: https://m4c0.itch.io/number-puzzle
